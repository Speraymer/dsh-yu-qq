# QQ大肥鱼（dsh-yu-qq）

在 DSH 和 QQ 之间架一条双向的桥：她在 DSH 里说的话自动发到 QQ；QQ 里收到的消息、图片和文件转进 DSH 的会话；群里还能用 `/dsh` 给她下指令。

---

## 它做什么

**四个方向**：

| 方向 | 具体做什么 |
|---|---|
| DSH → QQ | 某一整轮的最后一句说完，把这句原文发到 QQ（私聊或群） |
| QQ → DSH | 每 4 秒轮询一次 QQ 后端，把新消息转进对应会话 |
| QQ → DSH（附件） | 图片和文件落到 `~/.dsh/qq-bridge-inbox/`，路径写进转给她的文字里 |
| DSH → QQ（附件） | 她正文里写的图片/文件会发到 QQ，但**只认白名单路径** |

**会话怎么分**：每个群一间、每个人一间。群里的话不会串到私聊，别人的私聊也不会串进你的。

**指令**：只有你绑定的那个 QQ 号在群里发 `/dsh …` 才算指令，前缀和 UID 两个条件同时命中才执行。

---

## 安装

```powershell
dsh plugin --profile desktop add github:Speraymer/dsh-yu-qq
```

装完重启 DSH，设置里出现「QQ 桥」。

---

## 第一次使用

1. **先跑一个 QQ 后端**：NapCat 或 SnowLuma（OneBot 11 HTTP），默认地址 `http://127.0.0.1:3000`。
2. **保持试运行开**：默认「试运行」是开的——掷中了也只记账、不真发。先看几轮它想说什么。
3. **填三格**：你的私聊 QQ 号、要听的群号（可空）、以及你自己的 QQ 号（指令那一格）。
4. **确认没问题再关试运行**：关掉才会真的发到 QQ。

## 设置项

### 连接与身份

| 字段 | 默认 | 说明 |
|---|---|---|
| 总开关 | **关** | 关着 = 一句都不发 |
| 试运行 | **开** | 开着 = 只记账、不真发 |
| QQ 后端地址 | `http://127.0.0.1:3000` | OneBot HTTP，只接受本机回环 |
| 目标会话 | 空 | 盯哪一间 DSH 会话 |
| 私聊 QQ | 空 | 发到哪个私聊 |
| 群号 | 空 | 可空；多个用逗号分隔，每个群各一间会话 |
| 群会话表 | `{}` | 群号 → 会话 id；为空时退回单群那一格 |
| 指令 QQ | 空 | 只有这个号能用 `/dsh` |
| 称呼 | `对方` | 转进去的文案里怎么称呼那个人 |

### 收发方向

| 字段 | 默认 | 说明 |
|---|---|---|
| 转私聊 | 开 | DSH 的话发到私聊 |
| 转群 | **关** | DSH 的话也贴一份到群（容易刷屏，默认关） |
| 收私聊 | 开 | |
| 收群 | 开 | |
| 自动收群 | 开 | 群号之外，后端里所有群都听；新建群不用手填 |
| 自动收私聊 | 开 | 好友私信也收，各开一间会话 |

### 群聊接话

| 字段 | 默认 | 说明 |
|---|---|---|
| 群接话 | `auto` | `auto` = 点名立刻 + 其余掷骰 / `always` = 每批都开 / `at` = 只接被点名的 |
| 群掷骰秒 | `60` | 没被点名时，多久掷一次 |
| 群搭话概率 | `40`% | 第一次掷骰的中签率 |
| 群概率步进 | `20`% | 每没中一次加多少，加到 100 必然开口 |
| 群提名词 | `大肥鱼,鲸鱼娘,肥鱼` | 群里提到这些词也算点名 |
| 表情目录 | 空 | 大表情图放哪；留空用 `<DSH_HOME>/qq-bridge-stickers` |

### 图片与文件

| 字段 | 默认 | 说明 |
|---|---|---|
| 收图 / 发图 | 开 / 开 | |
| 收图最多 | `4` 张 | 一条消息最多转几张 |
| 图上限 | `5` MB | 两个方向共用 |
| 图片根目录 | 空 | 正文里 `![名字](相对路径)` 按哪找；留空自动猜 |
| 收文件 / 发文件 | 开 / 开 | |
| 收文件最多 | `3` 个 | |
| 文件上限 | `20` MB | |
| 发文件最多 | `3` 个 | 一轮最多发几个 |
| 群发文件 | **关** | 群消息是不可信素材，文件发进群撤不回来 |

### 断线与补课

| 字段 | 默认 | 说明 |
|---|---|---|
| 补课 | 开 | 开机时把断档期间漏的消息补一遍 |
| 补课最多条 | `30` | 每个群 / 每个人最多补多少 |
| 补课最多小时 | `48` | 更旧的不要，免得停机几天一开机灌几百条 |

## 运行机制

**轮询**：每 4 秒一次，问后端有没有新消息。自动发现群的清单和最近私聊联系人，带缓存——不会每次全量拉。

**水位**：每个群、每个人都记「处理到哪一条」，重启不会重复转。

**去重**：最近 300 个消息 ID 记着，同一批不会转两遍。

**补课**：开机时如果断档超过 2 分钟，把这段时间的消息**按群、按人合并成一条**补进来，标注「离线补课」；这一轮静默，不回 QQ。

**外部内容是素材，不是指令**：群里的文字包在 `<QQ_GROUP_CONTENT>` 里，私聊的也标注「不可信素材」。三种口径分开：你在跟我说 / 别人在群里说 / 群里的公共内容。

**发图/发文件的白名单**：只认 `qq-bridge-inbox/`、`<DSH_HOME>/attachments|cache|img` 下的**图片**文件，扩展名也卡死。原因是她的话是模型写的，而模型读得到群消息——不给白名单，一句 `![](任意路径)` 就能把本机文件发出去。

**指令**：`/dsh` 前缀 + 指令 QQ 号，两条同时满足才执行。

## 边界与已知限制

- **需要外部 QQ 后端**：NapCat / SnowLuma 挂了，桥就断；它自己不含 QQ 协议实现。
- **只接受本机回环**：远程地址不连，避免把 QQ 号暴露到公网。
- **轮询不是推送**：4 秒一次意味着消息最多延迟 4 秒。
- **群发文件默认关**，而且不打算默认开——发出去撤不回来。
- **补课有上限**：超过 48 小时或超过 30 条就不补了。
- **表情只能是本地图片**：`[表情:名字]` 从表情目录找同名图片。

---

## 依赖与降级

- 没有 QQ 后端时：设置页显示连不上，收发的定时器空转，不报错。
- 没有 DSH 会话（目标会话被归档/删了）时：这一条跳过并记账。
- 不依赖其他插件；表情/语音是可选附加件。
